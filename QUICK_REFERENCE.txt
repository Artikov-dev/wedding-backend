## 🔐 Authentication

```
1. Login to get token:
POST /api/auth/login
{"email":"user@example.com","password":"Secret123!"}

2. Use token in requests:
Authorization: Bearer YOUR_JWT_TOKEN

3. Refresh when expires:
POST /api/auth/refresh
{"refreshToken":"..."}
```

---

## 📝 Example API Calls

### Get Health Status (No Auth)
```bash
curl http://localhost:3000/api/health
```

### Search Halls (No Auth)
```bash
curl "http://localhost:3000/api/halls/search?city=New%20York"
```

### Create Booking (With Auth)
```bash
curl -X POST http://localhost:3000/api/bookings/create \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"hallId":"hall_123","eventDate":"2026-12-31",...}'
```

## 🛠️ Troubleshooting Quick Fixes

| Problem | Solution |
|---------|----------|
| Server won't start | `npm install` then `npm run dev` |
| Tests won't run | Start server first in another terminal |
| Port 3000 in use | `lsof -i :3000` then kill process |
| Auth errors | Check token with `/api/health` first |
| DB not connected | Check `.env` DATABASE_URL |
